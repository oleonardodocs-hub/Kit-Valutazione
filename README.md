# Kit Valutazione Salute Mentale (app)

Dashboard com 6 módulos de ferramentas (57 itens, Word e PDF) + Modulo VII Videolezioni (aulas em cenas animadas, sem vídeo).

- index.html: o aplicativo
- 1/ a 6/: arquivos de cada módulo, na RAIZ do repositório (nomes em LISTA-ARQUIVOS.txt)
- manifest.webmanifest, sw.js, icon.svg: instalação como aplicativo

Publicar: Settings > Pages > Deploy from a branch > main / (root) > Save.
